Unofficial local tool, not affiliated with CAPCOM or Rain Server.
The optional database is generated from separately supplied MHF data. Source archive names and SHA-256 hashes are preserved in the SQLite sources table; see SOURCE_CHECKSUMS.txt in the developer source. Original source archives are not bundled. Redistribution permission for third-party data has not been verified. Check applicable terms and notices before sharing or publishing a DB-inclusive package.
The Windows binary bundles Python and third-party dependencies; their own licenses apply. Review the distribution obligations and retain the required license and attribution files before public release. The Inno Setup compiler is a developer-only dependency and is not required by users. Its licensing terms also apply.
Version 1.4.0 optionally decodes Zstandard data packs using python-zstandard 0.25.0. Its BSD license is retained in licenses/zstandard-LICENSE.txt. Local/default data packs use Python's LZMA2 (XZ) implementation. PyRoaring is used only by the optional developer benchmark, not the application search runtime.
